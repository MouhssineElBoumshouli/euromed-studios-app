## What the floor plan tells us

These are read directly from `01-floor-plan.jpg`.

There are **4 rooms and 2 control rooms**:

| Room on the plan | What happens in it |
| --- | --- |
| Area 1 | Reception, VIP Room, Podcast Studio |
| Area 2 | TV Studio, Web TV Studio, Radio Studio |
| Area 3 | Chroma Key Studio, Photography Studio |
| Area 4 | E-Learning Studio, SpeedMOOC Studio |
| Production Control Room 01 | |
| Production Control Room 02 | |

There are also two make-up spots.

**Why this matters:** several "studios" are the same physical room. The photos of Plateau TV and Euromed Radio show the same set. So does the wide shot of the Podcast Studio and the Salon VIP. Booking one studio may block the other studios in the same room. UEMF needs to confirm this (see question Q1).
