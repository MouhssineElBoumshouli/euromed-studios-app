# Roadmap

Each phase ends with something we can show and check. We move to the next phase only after Mouhssine approves.

| # | Phase | What we get at the end | Who checks it besides us |
| --- | --- | --- | --- |
| 1 | **Requirements** | One clean requirements list traced to the Cahier des Charges, plus a question list sent to UEMF | Brahim Seddouki answers the questions |
| 2 | **Design system** | A new Figma file with colors, fonts, spacing and reusable parts, based on the Euromed Studios brand (navy and gold) | An accessibility contrast check |
| 3 | **Screens and prototype** | Every screen for every role, in a clickable prototype | 5 real users try the main tasks without help |
| 4 | **Technical foundation** | Login with UEMF accounts, the database, the rules for who can see what, and a test version online | UEMF IT reviews it |
| 5 | **Build in slices** | Working features, one at a time: browse studios → book → Level 1 approval → Level 2 approval → QR code → equipment → projects → incidents → admin | Automatic tests run on every change |
| 6 | **Harden** | Speed (under 200 ms, per the Cahier des Charges), security, accessibility, offline and error states | A security check and a performance test |
| 7 | **Pilot** | 1–2 weeks of real bookings at the studios | The studio staff and the approvers |
| 8 | **Launch and hand-over** | Published on the App Store and Google Play, with a guide for whoever runs it next | UEMF signs off |

## Now

Phases 1 and 2 are done: requirements and the design system. Phase 3 (screens and prototype) is in progress, and wave 1 is built: access, home, studios, booking, my bookings, QR and validations.
